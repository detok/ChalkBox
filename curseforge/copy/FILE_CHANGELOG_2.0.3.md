# ChalkBox 2.0.3

### Discoveries
- Fixed a presentation bug where the standalone Discoveries browser could show controls without a visible background when global background strength was very low or zero.
- Added a clear panel edge and ensured the journal is raised when opened.
- Guarded theme refreshes against missing or invalid color values.

### Unchanged
- Loot observations, map button position, dungeon and creature-source filters, item search, and sorting remain intact.
- The grouped settings navigation and quiet meter startup from 2.0.2 are preserved.
- No SavedVariables reset or data migration is required.

This is a WoW Forever testing build. Verify the journal in the live client before public promotion.

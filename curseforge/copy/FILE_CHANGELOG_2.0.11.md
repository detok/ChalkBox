# ChalkBox 2.0.11 — Better Discoveries browsing

### Discoveries
- Replaced the old nested area menu with a direct, scrollable zone and dungeon picker.
- Browse any recorded location in one click, with mouse-wheel navigation and paging.
- Follow world map or browse manually, preserving prior choices per character.
- Cleaner item statistics: Found, Drops and Rate with per-creature drops / looted attempts.
- Never combines unrelated creature samples into a made-up drop rate.
- Simplified DropSense tooltips, options and status text.

### Compatibility
- Works without native menu APIs for the area selector.
- Preserves all item history, filters, map controls, saved settings and previous fixes.

For WoW Forever; live-client visual verification recommended. Rates are personal samples of recorded loots, not official probabilities or all kills.

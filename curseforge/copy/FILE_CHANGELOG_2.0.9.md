# ChalkBox 2.0.9 — Discoveries location browser

### Map Discoveries
- Browse any recorded outdoor zone or dungeon directly from the existing Area / Dungeon dropdown.
- Added organized Outdoor zones and Dungeons submenus, alphabetical names and item counts.
- Choose Follow world map in the same dropdown, or toggle map sync from the existing top-right control.
- Selecting a location pauses map following without moving the Blizzard world map.
- Saved the last manually browsed location and map sync setting per character.
- Kept search, source filters, sorting, journal appearance and DropSense loot observations intact.

### Compatibility
- Supports both native and legacy client dropdown menus.
- Expanded automated regression checks for browsing, tab switching, map-follow behavior and saved selection.

World of Warcraft: Forever beta/test build; Retail and Classic Era remain unverified.

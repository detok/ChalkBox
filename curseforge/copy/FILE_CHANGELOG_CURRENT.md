# ChalkBox 2.2.29 — Stable Update

- **Combat Meter:** Disabled all ChalkBox fight reporting. Removed automatic after-combat chat, manual PARTY/SAY print actions, delayed report sends, copy-report prompts and their menu options. Old report commands silently do nothing. The personal DPS/healing meter, class icons, resizing and fight history continue working.
- **QuestSense:** Choose Closest First or Lowest Level First; completed objectives come last by default. Nearby searches verified quest locations across zone submaps and respects a five- or ten-quest selection budget.
- **The Bar:** Compact optional icons, clearer colored tooltips, per-module sizing and notch-safe layout.
- **AuctionSense / LootSense:** Inventory and recipe guidance, historical asking-price insights and verified loot information retained.
- **Discoveries:** World Map markers, recorded drops, learned flights and import/merge tools retained.

All existing saved settings and recorded personal data are preserved. The installable file is `ChalkBox-2.2.29.zip`; the separate media kit is not an addon.

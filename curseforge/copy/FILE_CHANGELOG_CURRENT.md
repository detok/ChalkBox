# ChalkBox 2.2.13 — Minimal QuestSense Compass

The quest navigator now displays **just the floating arrow**. The bulky bordered box, title/distance rows and visible buttons are gone.

- **Right-click** for Auto (follow tracked), Next quest, or Hide arrow.
- **Hover** to see the selected quest and straight-line yard distance.
- **Left-drag** to reposition; existing lock and reset controls remain in QuestSense → Navigation.
- When Forever can't calculate a direction, the arrow dims instead of pointing somewhere misleading.
- Automatic and manually selected quest targets, saved location, optional/off-by-default behavior and all existing QuestSense tracking remain intact.
- Compatible with both available modern and legacy in-game context menu APIs.

No changes to native quest watches, map waypoints, super-tracking or combat functions.

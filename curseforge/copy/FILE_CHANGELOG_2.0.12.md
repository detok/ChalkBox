# ChalkBox 2.0.12 — Discoveries picker and icon

### Fixed
- Discoveries Area / Dungeon dropdown now opens on top of the journal and world map, instead of being visible behind other controls and inaccessible.
- Popup remains anchored to the Area field, supports selecting zones and paging, and closes with the journal.

### Updated
- The in-game AddOns selection icon matches the newer ChalkBox gold-and-teal project artwork.
- Installable ZIP now includes the logo in native 64×64 uncompressed 32-bit TGA format.
- Extended regression tests for overlay layering and the packaged game icon.

### Unchanged
Map sync, saved loot and zone selections, creature filters, UI layout, other modules and SavedVariables.

WoW Forever test build; real-client visual verification is still required.

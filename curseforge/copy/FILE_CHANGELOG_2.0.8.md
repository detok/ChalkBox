# ChalkBox 2.0.8 — QuestSense Nearby

### QuestSense
- Nearby-only mode now stays synchronized to your current quest zone, with periodic fallback updates when events are missed.
- New distant quests and local-POI hints can't bypass the confirmed-zone filter.
- Out-of-zone manually watched quests are hidden temporarily and restored when they become local or another mode is selected.
- Manual unwatch decisions, watch limits, and native tracking behavior are preserved.
- Conservatively keeps watched quests if zone data is unavailable or the map, quest log, combat, or instance state prevents safe edits.
- Shows the active tracking mode and hidden-watch count in ChalkBox settings.

### Other modules
- Keeps Bar menus/tooltips, Discoveries, inventory responsiveness, layouts, and SavedVariables unchanged.

# Support, attribution and release maintenance

## Public support copy

**Issues, bugs and feature requests:** https://github.com/detok/ChalkBox/issues

To help reproduce a bug, include the **ChalkBox version**, your **Forever client/build**, the **module** affected, **steps to reproduce**, expected vs. actual results, and the **exact Lua error / chat message / tooltip**. A screenshot is useful when it shows the issue. Remove account or other private information from captures.

This is an independent **public prerelease**. Client-specific errors, especially in protected combat APIs or native Blizzard menus, are valuable testing feedback.

**CurseForge moderation note:** CurseForge's description should not link to a third-party downloadable ZIP; the platform expects its own file hosting. It can still include a non-download **source** link and issue tracker. On GitHub itself, promote the direct GitHub Release ZIP clearly and prominently.

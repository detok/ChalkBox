# ChalkBox command reference — source of truth

The **canonical and current command reference** is [docs/COMMANDS.md](../../docs/COMMANDS.md). It is checked against the Lua slash dispatcher and individual module commands.

**Publishing note:** `scripts/build_curseforge_kit.py` includes the canonical `docs/COMMANDS.md` under the media ZIP's `Copy-and-Checklist/copy/COMMANDS.md` path. This stub deliberately has **no duplicate command table** to become outdated.

Most common player commands:

- `/chalk` — open settings.
- `/chalk drops map` — open Discoveries.
- `/chalk quests smart` — choose Smart tracker mode; `/chalk quests status` reports dungeon matches.
- `/chalk macro` — open MacroForge.
- `/chalk auction status` — check a manual market scan.
- `/chalk bar edit` — toggle Bar editing.
- `/chalk meter show` — open the optional meter.
- `/chalk update` — installed version and release link.

Do not mistake an observed loot rate for an official drop chance or a generated macro for a combat-automation feature.

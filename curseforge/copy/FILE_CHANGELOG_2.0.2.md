# ChalkBox 2.0.2

### Settings
- Reorganized AddOns settings by module. The Bar contains **Modules** and **Appearance**; LootSense has **Appearance**; Adventure Prep has **Toast Appearance**; Emota has **Race Behavior** and **Emote Catalog**.
- Grouped the ChalkBox home page into three short sections, with a consistent header, divider and return-to-ChalkBox control on each module page.
- Kept the existing settings keys and preferences. You won't need to reconfigure your modules.

### Combat Meter
- The optional DPS meter now starts **closed** on every login, including if it was open before logout. Open it from Combat Meter settings or with /chalk meter show.

### Packaging and documentation
- Updated feature summaries and setup instructions for DropSense, Map Discoveries, MacroForge, LootSense, The Bar, Session Journal, QuestSense, CampSense and the rest of ChalkBox.
- Prepared a separate CurseForge media kit with six original SVG graphics, nine PNG exports, listing text, and a publishing checklist.
- Retained existing character data, loot history, macro recipes, module positions and learned repair prices.

This is a Forever-client testing release. The nested settings layout and startup behavior still need a live-client pass.

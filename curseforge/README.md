# ChalkBox — CurseForge publishing kit (2.2.22 stable)

**ChalkBox 2.2.22 is the first stable WoW Forever release.** The live full AuctionSense scan has been accepted in-game by the maintainer, and its observed pricing data is available to connected item and bag insights. Lua compatibility, test and packaging checks passed before the published ZIP was built.

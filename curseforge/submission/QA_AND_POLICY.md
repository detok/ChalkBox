# Submission QA and policy checklist

This file is for the author before publishing content to CurseForge and before promoting it from GitHub.

## 1. Copy quality

- [ ] The headline is clear to Forever players and doesn't claim an official Blizzard product
- [ ] Feature descriptions match source code in `../copy/FEATURE_PROOF.md`
- [ ] There are no unsupported modules, fake testimonials, invented performance numbers or “100% safe” claims
- [ ] Pricing, donations, support and Discord links are not invented
- [ ] There are no broken image references or unmade graphic placeholders on public pages
- [ ] File change log matches the actual uploaded version

## 2. File and third-party attribution

- [ ] Upload only the one verified, tested, installable **ChalkBox-<version>.zip**
- [ ] Do not upload a GitHub repository archive, marketing directory or loose `curseforge/` docs
- [ ] Top-level ZIP folder is exactly `ChalkBox/`
- [ ] Confirm `ChalkBox_Camelot.toc` and Forever game flavor selection
- [ ] Confirm library copyright/author/license notices: LibProfessionDB (MIT; Pimptasty), LibStub (public domain)
- [ ] Avoid embedded executables, uncredited artwork, and malware-like or external automation instructions
- [ ] Verify enough native UI support through a real-client test

## 3. Media accuracy

- [ ] Actual in-game screenshots are sourced from the game and are not synthetic reproductions
- [ ] Final logos/hero banners are clearly editorial/brand art, not fake UI screenshots
- [ ] Respect game art rights and third-party libraries
- [ ] Remove private character/party identifiers and sensitive whispers
- [ ] Review legibility in mobile thumbnail and crop
- [ ] Verify current upload limit and image dimensions on the portal itself

## 4. Platform-specific moderation rules

- [ ] The CurseForge public project description **does not contain direct external ZIP download links**
- [ ] The GitHub **source and bug-report links** remain functional and non-promotional
- [ ] Any allowed external social or portfolio links are placed according to current moderation requirements
- [ ] Exact platform game/version categories match Forever, not general retail
- [ ] In the GitHub README, **direct downloads from GitHub Releases ARE promoted**, because that is the preferred distribution path for the repository
- [ ] Review the latest [CurseForge moderation policy](https://support.curseforge.com/support/solutions/articles/9000197279-moderation-policies) before submission

## 5. Browser and client checks

- [ ] Description renders in the portal editor (Markdown/WYSIWYG as actually supported)
- [ ] No links point to uncreated CurseForge project or logo
- [ ] No `[image]` or broken media placeholders are visible to end users
- [ ] Actual uploaded addon ZIP installs, loads and persists saved settings
- [ ] Download and installation paths are short and accurate
- [ ] Download path from GitHub is clear on the repository homepage

## 6. Launch state

- [ ] GitHub README is polished and current
- [ ] `curseforge/` production pack is versioned and internally linked
- [ ] The art brief remains visibly “PENDING” until files exist
- [ ] CurseForge project is explicitly labeled **not submitted** until user publishes it
- [ ] Approval, rejection, or file change requests will be reflected after the actual review

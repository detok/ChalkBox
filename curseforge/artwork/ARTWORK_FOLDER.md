# ChalkBox artwork — stable-release upload guide

The **six original SVG masters** are the editable source artwork for ChalkBox. The media ZIP builds **nine PNG exports** from them. No assets in this folder change the in-game interface, and the visual identity is deliberately unchanged for the first stable release.

| Source artwork | Rendered PNG | Use |
| --- | --- | --- |
| `chalkbox-project-icon-512.svg` | `Artwork/PNG/Upload-Ready/Project-Icon-512.png` | **CurseForge project avatar** (512×512) |
| `chalkbox-wordmark.svg` | `Artwork/PNG/Upload-Ready/ChalkBox-Wordmark-1280x270.png` | Wordmark / brand graphic |
| `chalkbox-banner-1200x630.svg` | `Artwork/PNG/Upload-Ready/ChalkBox-Social-Banner-1200x630.png` | Promotional banner / GitHub social preview |
| `chalkbox-github-header-1600x470.svg` | `Artwork/PNG/Upload-Ready/ChalkBox-GitHub-Header-1600x470.png` | GitHub README header |
| `chalkbox-hero-1600x900.svg` | `Artwork/PNG/Editorial-Only/ChalkBox-Hero-1600x900.png` | Promotional illustration, **not a screenshot** |
| `chalkbox-feature-grid-1600x900.svg` | `Artwork/PNG/Editorial-Only/ChalkBox-Feature-Illustration-1600x900.png` | Editorial feature illustration, **not a screenshot** |

The exports also include square icon variants at 64, 128 and 256 pixels.

**Download:** [ChalkBox-CurseForge-Media-2.2.22.zip](https://github.com/detok/ChalkBox/releases/download/v2.2.22/ChalkBox-CurseForge-Media-2.2.22.zip). It also contains project copy, checklists and ten genuine older game captures. Only actual WoW screenshots should be placed in a gameplay gallery.

For uploading, start with [the publisher's kit](../launch-kit/START_HERE.md) and [screenshot guidance](SCREENSHOT_PLAN.md).

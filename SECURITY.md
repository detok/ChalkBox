# Security and responsible reporting

ChalkBox is a client-side World of Warcraft addon. It is not supposed to collect credentials, send network requests, modify other addons, or automate protected gameplay.

If you believe you've found a security issue or data exposure:
1. Use GitHub's **private vulnerability reporting** for this repository if that feature is enabled.
2. Otherwise, open a minimal issue asking for a private contact route, **without posting exploit details, secrets or private user data**.
3. Include affected ChalkBox version and the relevant in-game conditions when it's safe to do so.

For ordinary addon errors, use the public [bug report form](https://github.com/detok/ChalkBox/issues/new/choose).

No paid bug bounty or response time is promised.
